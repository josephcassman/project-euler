Code for the math problems at [projecteuler.net](https://projecteuler.net/about).

Each problem is placed in a separate executable file in the `/bin` folder. The format for a problem solution is `p` followed by the number of the problem padded to four digits. So, for example, `p0001` is the executable for _problem #1_.

Use the following command to execute a file, replacing `p0001` with the specific problem number to run:

```
cargo run --bin p0001
```
