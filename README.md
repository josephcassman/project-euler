Code for the math problems at [projecteuler.net](https://projecteuler.net/about).

Each problem is placed in a separate file in the `src/problems` folder. The format for a problem solution is `p` followed by the number of the problem padded to four digits. So, for example, `p0001` is the file for _problem #1_.

Use the following command to execute problem 1:

```
cargo run -- 1
```
